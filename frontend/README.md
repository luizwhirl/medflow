# MedFlow Web

Frontend em Angular 20 + Tailwind CSS 4.

```bash
npm install
npm start          # http://localhost:4200 (proxy /api -> http://localhost:8080)
npm run build      # build de produção em dist/medflow-web
npm run test:ci    # testes unitários (Chrome headless)
npm run format     # Prettier
```

Estrutura e convenções: [../docs/arquitetura.md](../docs/arquitetura.md).
